# 5-flow-conjecture

Working repository for an attack on Tutte's 5-flow conjecture:

> Every bridgeless graph admits a nowhere-zero 5-flow.

See https://www.openproblemgarden.org/op/5_flow_conjecture.

## Layout

- `survey/5-flow-survey.md` — the literature survey (foundations, minimal-counterexample ledger, proved classes, equivalent and stronger statements, techniques and why they stop at 6, attack routes, bibliography). Read this first.
- `book/` — local copy of C.-Q. Zhang, *Integer Flows and Cycle Covers of Graphs* (1997), the main reference for the classical theory. The PDF is not committed (copyrighted); place it at `book/1997-Book-flow.pdf` yourself.
- `docs/index.html` — the survey as a web page, served by GitHub Pages at https://geneweng.github.io/5-flow-conjecture/
