# Specification of the count relaxation for (C6)

*Working notes, 2026-09-19. Self-contained mathematical statement of the model behind Theorem 20.1 of `oddness.md`, written so that it can be re-implemented independently of `tools/count_c6.py`. Every constraint below is a necessary condition for the configuration to occur; so if the system has no solution, the configuration cannot occur.*

## 1. Setting

$G$ is a cyclically 6-edge-connected cubic graph on $n\ge42$ vertices (hence girth $\ge6$), $F_2$ a 2-factor with exactly six odd circuits $C_1,\dots,C_6$ (each of length $\ge7$) and any number of even circuits, $M$ the complementary perfect matching. The canonical colouring gives colour 1 to $M$; on each even circuit colours 2, 3 alternate; on each odd circuit one edge (the 0-edge) has colour 0 and the others alternate $2,3,\dots,2,3$ starting next to the 0-edge, so the 0-edge lies between a colour-2 and a colour-3 edge. The vertex $z_k$ of $C_k$ between the 0-edge and the colour-3 edge is the only vertex of $C_k$ with no colour-2 edge. $H$ = edges of colours 1 and 2: every vertex has $H$-degree 2 except the six $z$'s (degree 1, their $H$-edge has colour 1). We assume $H$ consists of three paths $P_0,P_1,P_2$ ($P_i$ from $z_{2i+1}$, its *start*, to $z_{2i+2}$) and some even circuits ("$H$-circuits"). Along every component of $H$ colours 1 and 2 alternate.

A *colouring* is a proper black/white 2-colouring of $H$ (each component has two). Fix the colouring of the $H$-circuits once and for all. A set $S\subseteq V$ is a **killer** of a colouring $\varepsilon$ if, with $k=\#\text{black}(S)-\#\text{white}(S)$ and $m=|\partial S|$, $c_1,c_2$ = numbers of colour-1, colour-2 edges in $\partial S$, one of:

- type **pair**: $m=6,k=4,c_1=4,c_2=2$, exactly two of the paths have exactly one end in $S$ ("separated"), both these ends black; the third path has both ends in $S$ or both outside;
- type **P7**: $m=7,k=5,c_1=5,c_2=2$, all three paths separated, the three ends in $S$ black;
- type **P641**: $m=6,k=4,c_1=4,c_2=1$, one boundary edge of colour 0 or 3 (the "non-$H$ edge"), all three paths separated, the three ends in $S$ black.

**Facts used (Lemmas 6.1, 6.2 of `oddness.md`).** For a killer $S$ of $\varepsilon$: (T1) every colour-1 and every colour-2 edge of $\partial S$ has its $S$-end black under $\varepsilon$ (and its other end white). (T2) Hence along a path $P_i$, walking from its start, the vertex colours alternate, the edges alternate $1,2,1,2,\dots$ starting with colour 1, and a crossing edge $v_tv_{t+1}$ ($v_0$ = start) has colour 1 iff $t$ is even; with $\beta$ = [start of $P_i$ is black under $\varepsilon$], a crossing that **leaves** $S$ has colour 1 if $\beta=1$ and colour 2 if $\beta=0$; a crossing that **enters** $S$ has colour 2 if $\beta=1$ and colour 1 if $\beta=0$. A separated path has $\beta=1$ iff its start is in $S$, and crosses $\partial S$ an odd number of times. A non-separated path crosses an even number of times. (T3) An $H$-circuit crosses $\partial S$ with equally many colour-1 and colour-2 edges.

An **item** is a killer together with the data: which paths are separated and which end is inside; for each non-separated path whether it *avoids* $\partial S$ (zero crossings) or *crosses* it (then $\ge2$ crossings, and $\beta\in\{0,1\}$ is part of the data); $(c_1,c_2)$; whether there is a non-$H$ edge. A **configuration** is a list of $J$ items $S_1,\dots,S_J$ (killers of possibly different colourings $\varepsilon_j$ of the paths; the $H$-circuits are coloured the same in all of them).

## 2. Variables

Atoms: $a\in\{0,1\}^J$, the atom $a$ is the set of vertices $v$ with $[v\in S_j]=a_j$ for all $j$; $D(a,b)=\{j:a_j\ne b_j\}$. The atom of each path end is given by the configuration.

- $n_a\in\mathbb Z_{\ge0}$: number of vertices of atom $a$.
- $x^i_{a\to b}\in\mathbb Z_{\ge0}$ for each path $i$ and ordered pair $a\ne b$: number of edges of $P_i$, traversed from the start, going from atom $a$ to atom $b$. The variable exists only if for every $j\in D(a,b)$ the path $i$ is separated by or crosses $S_j$, and the colours forced by (T2) for all $j\in D(a,b)$ agree (leaving $S_j$ iff $a_j=1$); that common colour is the colour $\gamma(i,a,b)\in\{1,2\}$ of these edges.
- $u^c_{a\to b}\in\mathbb Z_{\ge0}$, $c\in\{1,2\}$: number of colour-$c$ edges of $H$-circuits with black end in $a$ and white end in $b$. By (T1) the variable exists only if $a_j=1$ and $b_j=0$ for all $j\in D(a,b)$.
- For every unordered pair $\{a,b\}$ with $\emptyset\ne D(a,b)\subseteq NH$ ($NH$ = the set of P641 items) and every circuit class $\kappa$ (below): $e^\kappa_{ab}\in\{0,1\}$, "the non-$H$ edge joining $a$ and $b$ lies on a circuit of class $\kappa$".
- Circuit classes $\kappa\in\{1,\dots,6\}$ (the odd circuit of $z_\kappa$) and $\kappa=7$ (all even circuits of $F_2$ together). $w^\kappa_{ab}\in\mathbb Z_{\ge0}$ for unordered pairs: number of colour-2 edges between $a$ and $b$ lying on circuits of class $\kappa$.

## 3. Constraints

Write $E_1(a)$, $E_2(a)$ for the total number of colour-1, colour-2 edges (path and $H$-circuit edges, both directions) with exactly one end in atom $a$, $E_{nh}(a)=\sum_{\kappa,b}e^\kappa_{ab}$, $z(a)$ = number of path ends in $a$.

1. **Paths are walks.** For each path $i$ and atom $a$: out-flow minus in-flow of $x^i$ at $a$ equals $[a=\text{atom of start}]-[a=\text{atom of end}]$. Connectivity: the support of $x^i$ is connected to the start atom (can be imposed lazily).
2. **Crossing numbers.** For each item $j$ and path $i$: the number of crossings $\sum_{D(a,b)\ni j}x^i_{a\to b}$ is odd if $i$ is separated by $S_j$, even and $\ge2$ if $i$ crosses $S_j$ (and there are no variables if it avoids).
3. **Cut counts.** For each item $j$: $\sum_{c=1}u^c$ over pairs crossing $j$ equals $\sum_{c=2}u^c$ over pairs crossing $j$ (T3); the colour-1 edges crossing $j$ (paths and $H$-circuits) number $c_1(j)$, the colour-2 edges $c_2(j)$; exactly one non-$H$ edge crosses each P641 item, i.e. $\sum_{\kappa,\{a,b\}:D(a,b)\ni j}e^\kappa_{ab}=1$, and no non-$H$ edge crosses any other item (built into the index set of $e$).
4. **$H$-circuit segments.** In each atom $a$, with $B_c=\sum_bu^c_{a\to b}$, $W_c=\sum_bu^c_{b\to a}$: $B_1-B_2=W_1-W_2$. (A maximal segment of an $H$-circuit inside $a$ has two end-vertices; if they have equal colours the segment has an even number of edges and its two crossing edges have different colours, if different colours the same colour; count.)
5. **Atom sizes.** For each atom: $n_a\equiv E_1(a)\pmod2$ (matching inside the atom); $n_a\equiv E_2(a)+z(a)\pmod 2$ (colour-2 edges inside the atom cover all vertices except the $z$'s and the ends of leaving colour-2 edges); $E_2(a)+E_{nh}(a)$ even (every $F_2$-circuit crosses the boundary of $a$ an even number of times, through colour-2 or non-$H$ edges only); $E_2(a)+z(a)\le n_a$; $E_1(a)\le n_a$; $2n_a\ge2\cdot\#\{\text{visits of paths to }a\}+\#\{H\text{-circuit crossing edges at }a\}$, where the visits of $P_i$ to $a$ are its entries into $a$ plus one if it starts in $a$; if $z(a)>0$ then $n_a+E_{nh}(a)\ge3$ (a $z$ and its two circuit neighbours, joined to it by edges of colours 0 and 3, are in the same atom unless one of these two edges is a non-$H$ boundary edge); if no path starts in $a$ and $E_1(a)+E_2(a)+E_{nh}(a)=0$ then $n_a=0$ (connectivity). $\sum_an_a\ge42$.
6. **$F_2$-circuits as closed walks.** $\sum_\kappa w^\kappa_{ab}$ = total number of colour-2 edges between $a$ and $b$. For each class $\kappa$ and atom $a$ the degree $\deg_\kappa(a)=\sum_bw^\kappa_{ab}+\sum_be^\kappa_{ab}$ is even. For $\kappa\le6$ with $z_\kappa$ in atom $a$: if $n_a\le6$ then $\deg_\kappa(a)\ge2$ (the circuit has $\ge7$ vertices); if $n_a=3$ and $E_{nh}(a)=0$ then $\deg_\kappa(a)=2$ and $\deg_{\kappa'}(a)=0$ for all $\kappa'\ne\kappa$ (the atom is $z_\kappa$ with its two circuit neighbours; their third circuit edges have colour 2; the three matching edges leave). Connectivity: the support of class $\kappa\le6$, if non-empty, is connected to the atom of $z_\kappa$ (lazy).
7. **Union facts.** For every set $U$ of atoms, with $n_U=\sum_{a\in U}n_a$, $\bar n_U=\sum_an_a-n_U$ and $d_U$ = number of all edges (path, $H$-circuit, non-$H$) between $U$ and its complement: $d_U\le3n_U$, $d_U\le3\bar n_U$; if $n_U=0$ or $\bar n_U=0$ then $d_U=0$; otherwise $d_U\ge3$; if $1\le n_U\le5$ then $d_U\ge n_U+2$ (a set of at most 5 vertices is acyclic), same for $\bar n_U$; if $n_U\ge4$ and $\bar n_U\ge4$ then $d_U\ge6$ (cyclic 6-edge-connectivity; sides of 4 or 5 vertices are covered by the previous bound). These may be imposed for all $2^{2^J}$ unions or lazily for violated ones; any subset gives a valid relaxation.

Upper bounds used in the implementation and harmless: $x,w\le11$, $u\le5$ (no item has more than 7 boundary edges, so per-item sums bound everything crossing at least one item), $n_a\le500$ (all constraints on $n_a$ are lower bounds, parities, or thresholds at most 6, so a solution with larger atoms can be shrunk by even amounts).

## 4. The items and the covers

Classes of path colourings up to complement: normalise $z_1$ black; class $(b_2,b_3)$ has $z_3$ black iff $b_2=0$ and $z_5$ black iff $b_3=0$ (each path has one black and one white end). A killer contains the black ends of the separated paths.

- **Points** of class $(b_2,b_3)$: P7 and P641 with membership $z_1\in S$, $z_2\notin S$, $z_3\in S$ iff $b_2=0$, $z_4\in S$ iff $b_2=1$, $z_5\in S$ iff $b_3=0$, $z_6\in S$ iff $b_3=1$; and the crossed pair cuts $Pc(i,p)$, $i\in\{0,1,2\}$, $p\in\{0,1\}$: same membership except that both ends of $P_i$ are in $S$ ($p=1$) or outside ($p=0$), $P_i$ crosses with $\beta=1$ for $i=0$, $\beta=1-b_2$ for $i=1$, $\beta=1-b_3$ for $i=2$. Eight points per class.
- **Lines** (pair cuts avoided by the third path, which kill two classes): for the pair $\{0,1\}$, sign $b$, placement $p$: $z_1\in S$, $z_2\notin S$, $z_3\in S$ iff $b=0$, $z_4\in S$ iff $b=1$, $z_5,z_6\in S$ iff $p=1$; kills the classes with $b_2=b$. Pair $\{0,2\}$ analogously with $z_5,z_6$ and $b_3=b$, third path $P_1$. Pair $\{1,2\}$: $z_3\in S$, $z_4\notin S$, $z_5\in S$ iff $b=0$, $z_6\in S$ iff $b=1$, $z_1,z_2\in S$ iff $p=1$; kills the classes with $b_2=b_3$ if $b=0$ and with $b_2\ne b_3$ if $b=1$.

A **minimal cover** is an inclusion-minimal set of items whose killed classes cover all four classes (two points of the same class never occur together): two lines with complementary class sets; three lines covering all classes minimally; two lines missing one class plus a point of that class; one line plus one point for each of the two missing classes; four points, one per class. There are 5,292 minimal covers. **Claim:** the system of §3 is infeasible for each of them (it suffices that some sub-list of the cover is infeasible, since a sub-configuration of a realizable configuration is realizable).
